# Restaurant Backend

A simple Node.js and Express backend for the restaurant application.

## Getting Started

1. Install dependencies:
   npm install
2. Start the server:
   npm start

## Project Structure

- src/ - application source code
- .env - environment variables (not committed)

## Environment Variables

Create a `.env` file in the backend root and add variables such as:

PORT=5000

## Notes

This project is intentionally simple and can be extended with routes, controllers, services, and database integration.
